# Emerging — Resources Hub (mockup)

Bilingual (EN/FR) working mockup of the new **Resources** page for [emerging.fr](https://emerging.fr).
A single, filterable content repository for Emerging's employability research.

## What it shows

- **One repository, faceted filtering** — the GEURS and Digital Leaders "universes" are pre-filtered views of the same content, not separate silos.
- **5 content types:** Findings · Analyses · Articles · Widgets · Methodology.
- **Themes** grouped from the real data taxonomy (Employability & workforce readiness, Skills & upskilling, University-employer relations, Future of higher education, Programs & academic profile, Reputation & global impact).
- **Widgets** as interactive, embeddable tools (ranking explorer, comparator, GEURS Radar).
- **Public vs. client-only** content handled natively.
- **EN / FR** language toggle (top right). English is the default.
- Light / dark theme aware.

## View it

Single self-contained `index.html` (only external dependency is Google Fonts).

- Open `index.html` directly in a browser, **or**
- Publish with **GitHub Pages**: push this folder to a repo, then in *Settings → Pages* set the source to the `main` branch / root. The page will be served at `https://<user>.github.io/<repo>/`.
